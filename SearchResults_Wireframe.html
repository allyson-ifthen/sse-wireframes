⚑ Open Questions — Search Results

  • #1 CRITICAL CMS search capability: Does the selected CMS support native site search with result-type differentiation, or is a dedicated search tool (Algolia, Typesense, Elasticsearch) required? Wireframe defines the UX regardless — but implementation complexity depends heavily on this decision. Confirm during CMS evaluation.
  • #2 REVERSED (SR-3, 2026-08-02) LDC filter: previously resolved as "LDC selection is a sidebar filter, pre-populated from site context." Reversed — no search content is actually utility/LDC-specific, so gating results behind a utility selection doesn't reflect anything real. The "Your Utility" sidebar filter and the "No Utility Selected" page state have been removed entirely. Flagged per project convention rather than silently deleted.
  • #3 RESOLVED Filter taxonomy: Category filters use the LC pillar taxonomy (Understanding Gas Rates, Service Area & Setup, How to Switch, Managing Account & Bill, Carbon Neutral Gas for ONG/GRE) + Plans + Utility Contact + Legal. FAQ-format content routes to LC articles — no standalone FAQ result type in search. Residential/Commercial differentiated via inline badges on plan results.
  • #4 Utility contact results: For queries like "Columbia Gas phone number", should the search surface the LDC emergency contact from the Contact page directly in search results? Wireframe shows a "Utility Contact" result type for this use case.
