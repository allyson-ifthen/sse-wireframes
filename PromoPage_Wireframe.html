↳ URL Architecture — Promotional Pages
Canonical URL
/offers/{promo-code}/
One CMS page per promotion. Promo code is path-based (not a query parameter) — cleaner for analytics, CMS management, and printed materials.

Example: ohionaturalgas.com/offers/save25/
Vanity URL (Physical / OOH)
/{promo-code}/ → 301 → /offers/{promo-code}/
Root-level redirect set up in CMS for printed materials, door hangers, and mailers where URL length matters. No additional page required — just a redirect rule.

Example: ohionaturalgas.com/save25 → /offers/save25/
/offers/ Hub
/offers/ → 301 → /residential-plans/
No hub/index page needed — users don't browse for promo codes. The /offers/ root simply redirects to Residential Plans. Avoids a maintenance-heavy "all offers" listing.
Expired / Invalid Promos
410 Gone — or → /residential-plans/
Expired promo pages return a 410 (Gone) or redirect to /residential-plans/ — not a soft 404. This signals to search engines the page intentionally no longer exists and prevents expired offers from accumulating in the index.
